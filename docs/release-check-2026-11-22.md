日期为 2026-11-22，适用 Windows 10/11 x64。最终 ZIP 共 12,629,833 字节，SHA-256 为 `63b1a33c1d080cce1860a470205433050be5e16c2224de80657c49dd7e4e4594`。

## 发布和安装

向用户提供这一份 ZIP 即可。可交给 Codex 安装；手工安装时，完整解压后从解压目录运行「安装Skill.cmd」，升级也使用这个入口。首次从 PyPI 获取四个固定版本的基础发行文件，共约 55 MB；逐个比对 SHA-256。安装或缓存完成后可以离线审片。声音处理单独选择。公开 ZIP 不再随包分发 PyAV 的 FFmpeg DLL 或 imageio-ffmpeg 的 FFmpeg 可执行文件。

## 原包发现、修复与回归

| 问题 | 原包复现 | 修复后检查 |
|---|---|---|
| 正在运行时覆盖安装 | Windows 拒绝迁移正在使用的 Skill 目录 | 空闲服务可升级并在原端口恢复；运行任务会阻止升级；模拟激活失败后，原 Skill、设置与服务恢复 |
| API 错误后无法再工作 | 明确拒绝被登记为未知，缺少任务编号时一直无法解锁 | 区分明确拒绝、上传失败与受理情况未知；补填任务编号只查询；经人工核实未受理的任务可以结束；未自动重提 |
| 服务或凭据切换 | 旧标签页显示的服务可能与后台提交目标不同 | 过期确认返回 409，模拟供应商收到零笔提交；已有项目更换 API 绑定需要明确确认 |
| 跨窗口剪辑 | 另一窗口已改成第 20 帧，当前页还显示、可重新提交第 30 帧 | 干净页面跟随最新剪点；本地有草稿时保留草稿，拒绝旧版本提交，可主动载入最新状态 |
| 音频状态与媒体时间 | 旧项目缺模型时无法恢复原对白；部分音轨延迟或较短的素材在导出阶段才失败 | 无声音组件可恢复原声后导出；音视频偏移和短音轨得到处理；标准素材保留原文件；并发写入保留彼此的配置 |
| 包内容与指令 | 构建扫描嵌套工作台的范围过宽；安装和协议说明有旧版措辞；第三方模块声明不完整 | 限制 Skill 打包范围；改为先运行安装脚本；区分 CLI 与审片台协议；补充第三方声明并调整公开分发方式 |

## 最终包验证范围

- 三个子 agent 独立检查安装、生成及声音分支；主任务重新从最终 ZIP 安装。测试使用同一台 Windows 实机上的隔离用户目录、媒体目录及缓存。正式用户的项目、密钥和旧发布 ZIP 未被替换。
- 冷缓存真实下载、完整性校验、断网后启动和运行中升级通过。冷缓存且断网时安装明确失败，原有 Skill 保留。官方 Skill 结构校验通过。14 项剪辑、17 项 API 适配、8 项星幕配置、5 项抽帧检查全部通过。
- 真实浏览器验证播放、导入两个片段、切换候选、逐帧选点、接缝连播、103 帧导出和播放。
- 两种 API 协议在隔离 HTTPS 服务上验证了只读设置、实际提交请求、轮询、参考帧内容、收集 MP4 及错误恢复。真实星幕 1.9.9 完成握手、工具枚举、工作区读取和 Muse 模型查询。此次没有发起真实供应商的付费生成。
- 4 组媒体覆盖正常、音频晚 0.25 秒、视频晚 0.25 秒、音轨较短，各导出 72 帧。纯视频 API 回传补静音后可审片。缺模型恢复、CPU 分轨和并发设置回归通过。
- RTX 4060 Ti 16 GB 上用最终包的解释器、隔离 CUDA 环境和已有权重完成 10 秒样片重配、词级对齐和笑声处理。样片画面哈希一致，该句的自动复核最大发音偏差为 40 毫秒。音色主观听感不在自动检查范围。
- ZIP 的 CRC、SHA-256 和条目唯一性通过。公开包有两段合成测试素材；未混入检查项里的个人项目、参考录音、实际账号配置或模型权重。

## 发布说明中应保留的条件

首次安装需能访问基础组件下载源；星幕由接收者自行登录并配对；自带 API 需符合已支持协议。此次没有在所有 Windows 版本和显卡上逐一安装，也没有从空缓存重新下载全部大型声音模型。
